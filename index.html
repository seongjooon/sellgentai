Sellgent AI

쿠팡 로켓그로스 마진 계산기

쿠팡 상품 페이지에서 아이콘 한 번만 누르면, 로켓그로스 판매수수료·부가세·사이즈별 물류비를 반영한 예상 순이익과 마진율을 사이드바에서 바로 확인할 수 있는 크롬 확장 프로그램입니다.

크롬 웹스토어에서 설치하기

주요 기능

  • 상품 정보 자동 인식상품명, 판매가, 배송비, 카테고리, 판매자, 평점과 리뷰 수를 페이지에서 읽어옵니다.
  • 카테고리별 판매수수료카테고리에 맞는 로켓그로스 판매수수료율을 자동으로 적용합니다.
  • 사이즈별 물류비와 부가세상품 크기 6단계에 따른 입출고·배송비와 부가세 10%를 반영합니다.
  • 순이익·마진율 한눈에예상 순이익, 마진율, 비용 구성 비율을 색상과 차트로 보여줍니다.
  • 목표 마진과 최대 사입가목표 마진율을 정하면 그에 맞는 추천 최대 사입가를 알려줍니다.
  • 쿠팡 직매입 상품 경고쿠팡이 직접 판매하는 상품이면 경쟁이 어렵다고 미리 알려줍니다.

사용 방법

  1. 크롬 웹스토어에서 Sellgent AI를 설치합니다.
  2. 쿠팡 상품 페이지를 엽니다.
  3. 브라우저 오른쪽 위의 Sellgent AI 아이콘을 누르면 사이드바에 계산 결과가 나타납니다.
  4. 원가(사입가)와 상품 크기를 조정하면 순이익과 마진율이 바로 다시 계산됩니다.

자주 묻는 질문

계산에 포함되지 않는 비용이 있나요?
보관료, 반품비, 광고비는 자동 계산에 포함되지 않습니다. 계산 결과는 예상치이며, 정확한 금액은 쿠팡 WING 정산 내역을 확인해 주세요.
입력한 원가나 계산 결과가 서버로 전송되나요?
아니요. 계산은 브라우저 안에서만 처리되고, 계산 기록은 사용자의 브라우저에만 최근 10개까지 저장됩니다.
어떤 페이지에서 동작하나요?
크롬 브라우저의 쿠팡(coupang.com) 상품 페이지에서 동작합니다.
